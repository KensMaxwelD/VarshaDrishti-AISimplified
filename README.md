# VarshaDrishti AI — Vercel + Open-Meteo

This prototype uses Open-Meteo for live weather data through the Vercel `/api/weather` serverless function.
No API key is required for Open-Meteo's non-commercial API.

## Deploy
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. No environment variable is required for weather access.
4. Deploy and test the **Refresh Weather** button.

Open-Meteo attribution should remain visible in the application because its weather data are provided under CC BY 4.0.
